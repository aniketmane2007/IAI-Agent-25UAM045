# C4 Level 4 – Code Level Overview

The code level focuses on the main implementation functions rather than a large code diagram.

- `get_initial_state()` – obtains the starting puzzle configuration.
- `is_solvable()` – checks whether the supplied puzzle can be solved.
- `get_neighbors()` – generates valid neighboring puzzle states.
- `bfs()` – performs Breadth-First Search.
- `dfs()` – performs Depth-First Search.
- `display_grid()` – displays a puzzle state in grid form.
- `measure_bfs()` / `measure_dfs()` – records search/performance measurements.

> Before final submission, keep the function names consistent with the actual SLE-2 source code.
